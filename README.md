# FireCast AI — Near-Real-Time Disaster Perimeter & Spread Forecasting
> **Space Tech Hackathon Prototype** | Earth Observation & Meteorological Intelligence for Wildfire Response

FireCast AI demonstrates how satellite-based thermal anomaly detections and local weather intelligence can empower incident command teams to monitor wildfire perimeters and explore directional spread risk over 6-to-12 hour horizons.

---

## 🌟 Key Features

1. **Space-Borne Thermal Anomaly Hotspots**:
   - Ingestion of VIIRS 375m (S-NPP / NOAA-20) and MODIS 1km satellite thermal hotspots.
   - Hotspot clustering with Fire Radiative Power (MW) and brightness temperature (K).
   - Informational disclaimer distinguishing discrete satellite pixels from continuous ground perimeters.

2. **Interactive Tactical GIS Map (Leaflet)**:
   - Dynamic map layers: Satellite Hotspots, Observed/Estimated Perimeter, +6h Risk Zone, +12h Risk Envelope.
   - Basemap switcher: CartoDB Dark Matter, Esri World Imagery (Satellite), and Topographic.
   - Dynamic compass wind vector HUD with surface wind speed and heading.
   - Coordinate inspection on click with latitude & longitude HUD readout.

3. **Temporal Spread Simulation (0h / +6h / +12h)**:
   - Vector Huygens-inspired elliptical spread simulation model informed by real-time wind speed & direction.
   - Auto-simulation playback loop for dynamic mission briefing walkthroughs.
   - Dynamic calculation of estimated spread rate (km/h), projected burn area (ha), and downwind bearing.

4. **Meteorological Intelligence (Open-Meteo Integration)**:
   - Live surface weather metrics: Temperature (°C), Relative Humidity (%), Wind Speed & Direction, Atmospheric Pressure.
   - Interactive 12-hour hourly forecast area chart (`Recharts`) tracking temperature vs. humidity curves.
   - Direct live connection to Open-Meteo with seamless fallback if offline.

5. **Incident Decision Support & Alerts**:
   - Incident switcher with multi-regional scenarios: *Creek Fire Complex (CA)*, *Hermits Peak Fire (NM)*, *McDougall Creek (BC)*.
   - Tactical risk alerts identifying threatened sectors, smoke columns, and responder safety recommendations.
   - Explicit disclaimer highlighting informational decision-support status.

6. **Enterprise Backend Ready (Supabase)**:
   - PostgreSQL schema with Row Level Security (RLS) for `incidents`, `fire_observations`, `weather_observations`, `forecast_runs`, and `alerts`.
   - 4 Supabase Edge Functions (`get-fire-observations`, `get-weather`, `generate-forecast`, `refresh-incident`).
   - Zero-crash offline prototype engine: runs 100% functional in demo mode without mandatory backend credentials.

## 🗄️ Supabase Configuration & Migrations

If deploying with a live Supabase backend:

1. **Run Database Migrations**:
   Execute the migration script located at:
   `supabase/migrations/20250101000000_create_firecast_tables.sql`
   and seed initial data with `supabase/seed.sql`.

2. **Configure Supabase Secrets**:
   Set your NASA FIRMS API key in Supabase Secrets:
   ```bash
   supabase secrets set FIRMS_MAP_KEY=your_firms_map_key
   ```

3. **Frontend Connection**:
   Create `.env.local`:
   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-public-key
   ```

## ⚠️ Scientific & Operational Limitations

- **Demonstration Prototype**: The spread projections shown are generated by a simplified empirical wind-terrain vector spread calculation for hackathon demonstration. It is **not** a certified physics-based fire behavior model (such as FARSITE or Prometheus).
- **Not for Official Evacuation Orders**: Tactical alerts and risk polygons are decision-support concepts only. Emergency responders must rely on official jurisdictional command and evacuation directives.
- **Satellite Detection Geometry**: VIIRS pixel centroids represent thermal anomalies detected at the time of satellite overpass; clouds, smoke, or sensor angle can obscure ground perimeters.
